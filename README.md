# 📚 novel-scraper

> 让 CodeBuddy 化身「专业书虫」，专啃那些会反爬的小说站。

## 这是什么？

一个给 [CodeBuddy](https://www.codebuddy.ai) 用的 **skill**——一套「抓小说」的武林秘籍。

它不是独立的爬虫程序，而是一份给 AI 的「使用说明书」：当你说一句「帮我抓一下这本小说」，AI 就照着这套流程——**探测站点 → 绕过反爬 → 抓正文 → 洗掉广告 → 存成 txt**——一条龙搞定。

## 为什么需要它？

抓小说听起来简单，实际全是坑：

- 🌪️ **Cloudflare 人机验证**：你以为「请稍候…」是网速慢？不，是网站在跟你玩「猜猜我是不是机器人」。
- 🔐 **加密 API**：有的站把正文藏在 AES 加密的接口后面，参数还是混淆过的代码。
- 🕵️ **防盗水印**：每段正文后面塞一串随机字符，就等你复制粘贴时露馅。
- 📢 **牛皮癣广告**：`请收藏：www.xxx.com`、`更多精彩章节：yyy.vip`……删到手软。

这个 skill 把这些问题**踩过的坑都记下来了**，下次直接抄近路，不用再摔一遍。

## 能干什么？

- 🌐 **全网搜索**：只丢个书名，自动搜遍全网、比对哪个站资源最全最新
- 🧩 **正版 + 盗版拼接**：免费站抓大头，正版站补最新章节
- 🔍 自动判断网站类型：SSR 还是 SPA？要登录吗？要挂代理吗？
- 🛡️ 应对 Cloudflare、加密 API、登录态、防盗水印
- 🧹 清洗广告语、随机水印、HTML 实体
- ⚡ 增量更新：只抓缺的章节，不重复全量
- 🔁 断点续传：抓到一半失败也不怕，接着来

## 怎么用？（两种方式）

### 方式一：精确下载（你有网址）

直接把小说网站链接丢给 CodeBuddy：

> 帮我抓取 https://xxx.com/book/123 这本小说

它就会照流程探测站点、抓正文、洗广告、存 txt。

### 方式二：全网搜索下载（你只有书名）

**连网址都不用找**，只说书名：

> 帮我把《书名》下载成 txt

它会全网搜索候选资源 → 比对章节完整度/乱码/收费 → 给你方案，确认后再抓取。遇到免费站缺最新章节、正版站又更全的情况，会自动提出「拼接」方案，并告诉你哪里需要提供 cookie。

## 安装

把整个目录放到 CodeBuddy 的 skills 目录：

```bash
# Windows
xcopy novel-scraper "%USERPROFILE%\.codebuddy\skills\novel-scraper\" /E /I

# macOS / Linux
cp -r novel-scraper ~/.codebuddy/skills/
```

装好后，直接对 CodeBuddy 说书名或网址即可，用法见上方「怎么用？」。

完整过程见 `examples/`。

## 核心方法论（三句话）

1. **先探测再动手**——拿到目录页和第一章样本、看清正文结构和广告位置，再写批量抓取。
2. **加密 API 不必硬啃**——用浏览器加载站点，直接调用站点自己的加密函数生成 URL。
3. **抓取与生成分离**——先存中间态 `raw.json`，再幂等地生成 txt，清洗规则改了不用重新抓。
