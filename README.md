# novel-scraper —— 小说下载 Skill

一句书名，或一个网址，就能把网络小说存成 txt（也支持 epub）。免费站、书屋类站点都能抓，广告和水印自动清掉。

---

## 能下载什么网站？

| 网站类型 | 支持情况 |
|---------|---------|
| 免费小说站（笔趣阁系、书屋类等） | 直接下 |
| 单页应用站 | 直接下 |
| 需要登录的站 | 需提供 cookies |
| 需要翻墙才能访问的站 | 前提是你本机能访问 |
| PO18（po18.tw / 脸红心跳） | 有门槛，见下方专章 |
| 强人机验证站点 | 可能失败，会优先换镜像源 |

---

## 需要翻墙吗？

取决于目标网站本身。你本机能打开的站，它就能抓；被墙的站，你本机开着代理就行，不用再单独填代理地址。

实在访问不了，它会帮你换别的源，或告诉你哪些内容拿不到。

---

## 付费章节的限制

免费章节，以及你账号里已经买过的章节，都能下载。没买的下载不了——正文是服务器在你购买后才会发出来的。

买完重新跑一次，已购章节会自动补上，抓过的不会重复抓。

---

## 怎么用？

### 方案 A：我有网址，直接下载

最省事，把链接丢过来就行。

1. 发目录页链接给它。
   > 帮我抓取 https://xxx.com/book/123 这本小说
2. 它先探测站点、确认正文结构，没问题再开抓。
3. 批量抓正文，顺手洗掉广告和水印。
4. 输出 `书名 by作者.txt`，直接导入阅读器。

### 方案 B：我只有书名，全网找

连网址都不用找。

1. 告诉它书名，有作者名更好。
   > 帮我把《书名》下载成 txt
2. 它全网找候选源，比对章节全不全、有没有乱码、要不要钱。
3. 给你一份方案：推荐哪个源、各缺哪些章节。
4. 你确认后开始下载。

免费源差最后几章、正版站又齐全时，它会建议「免费站抓大部分 + 正版站补末尾」，并说明哪一步需要你提供 cookie。

### 方案 C：补章 / 更新

已经抓过一部分，想补新章或补漏章。

> 《书名》第 307 章是空的，帮我补一下

它会定位那一章替换掉占位内容；单纯更新的话，只抓缺的。

### 存成什么格式？

默认 txt，排版干净，拖进手机或阅读器就能看。

想要 epub（带章节目录、可导入 Kindle / 微信读书），跟它说一声即可。

## PO18 专章（po18.tw）

### 三个前提，缺一不可

1. 能访问：需要代理，你本机浏览器得能打开 PO18。
2. 已登录：未登录看不到任何正文。
3. 想看的付费章已购买。

### 三种提供登录状态的方式（选一个）

| 方式 | 怎么做 |
|------|--------|
| **① 导出 cookies（推荐）** | 装个浏览器插件，点一下复制，存成文件 |
| **② 浏览器登录一次** | 运行时加 `--state`，弹出浏览器让你手动登录一次，之后自动复用 |
| **③ 账号密码** | 不推荐，容易触发风控 |

#### 怎么导出 cookies（方式 ①）

1. 装插件：Chrome 应用商店搜 `Cookie-Editor` 装上。
   - https://chromewebstore.google.com/detail/cookie-editor/hlkenndednhfkekhgcdicdfddnkalmdm
2. 在 Chrome 里正常登录 https://www.po18.tw 。
3. 停留在任意 PO18 页面，点插件图标，再点顶部的 **copy**。
   - cookie 跟具体哪本书无关，在 PO18 哪一页复制都一样；但必须先登录。
4. 粘贴进新文件，保存为 `po18_cookies.json`，跟脚本放一起。
5. 运行时加上 `--cookies po18_cookies.json`。

> 这个文件能一直用，抓别的书也不用重新导。cookie 有时效，之后突然抓不动了，重新导一次即可。

其他站点的 cookie 导出教程：https://cookie-editor.com/

### 一键抓取命令

```bash
# 依赖（首次一次性安装）
npm install -g patchright

# 抓一本书
node po18_fetch.mjs https://www.po18.tw/books/903172/articles --cookies po18_cookies.json

# 常用参数
#   --list        只看目录和付费情况
#   --out ./小说   指定输出目录
#   --state s.json 用浏览器登录态代替 cookies
```

### 抓取过程中会看到什么

1. 验证登录态（页面上有「登出」或「xxx您好!」才算登录成功）。
2. 解析完整目录，标出哪些是付费章。
3. 逐章抓正文，每章完成即落盘，中途失败重跑会自动跳过已完成的。
4. 最后生成 `《书名》by作者.txt`；未购买的付费章列在结尾，买了重跑就能补上。

---

## 它抓不到时会怎样

| 情况 | 它的处理 |
|------|---------|
| 被强人机验证挡死 | 优先换镜像源，不行另想办法 |
| 站点被墙、你也访问不了 | 问你是否接受其他源，或只抓能抓的部分 |
| cookie 过期 | 先验证登录态再开抓，不会白跑一整轮 |
| 付费章没买 | 跳过并在结尾列出，不中断 |
| 抓一半断网 | 已抓的部分都在，重跑接着来 |

## 安装

把整个 `novel-scraper` 目录放进你的 skills 目录：

```bash
# Windows
xcopy novel-scraper "%USERPROFILE%\.codebuddy\skills\novel-scraper\" /E /I

# macOS / Linux
cp -r novel-scraper ~/.codebuddy/skills/
```

用别的支持 skill 的 agent 也行，把 `SKILL.md` 及同目录内容按该 agent 的约定放好即可。

装好后直接说书名或网址，用法见上方「怎么用？」。
